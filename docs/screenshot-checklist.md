# 最终教程真实截图清单

生成图已经放在 `docs/images/`。以下 10 张必须使用真实产品页面，由用户在最终发布前截取。

1. 账号库：平台、昵称、粉丝数、启用监控、最近成功时间、监控状态。
2. 内容库：封面、标题、账号、发布时间、点赞、收藏、增量、跟进状态、拆解文档。
3. 六个视图标签栏与“待处理新内容”。
4. 灵感画册：封面、标题、账号与互动数据。
5. 翻拍执行看板：待处理、待拆解、拆解中、已建档等状态列。
6. 单条内容详情：封面附件、媒体附件、ASR、已建档状态与拆解链接。
7. 飞书妙记逐字稿与对应拆解文档。
8. 飞书私聊中的 Card 2.0 战报。
9. 完整仪表盘：KPI、平台分布、账号互动和趋势组件。
10. Codex 自动化卡片与一次成功运行结果。

截图前应隐藏 TikHub Key、飞书 Token、用户 open_id、记录 ID、调试日志和任何不必要的个人信息。
