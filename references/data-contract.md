# 数据契约

## 业务键

- 账号：`platform:account_id`
- 内容：`platform:content_id`
- 评论：`platform:comment_id`
- 指标快照：`platform:content_id:bucket_time`

昵称、标题、主页链接和分享短链都可能变化，不得作为唯一键。缺少平台稳定 ID 时只能生成标记为 `weak` 的候选键，必须进入人工确认队列。

## 主业务表

- `账号库`：监控名单与账号当前状态。
- `内容库`：作品当前状态、运营流转和拆解链接。

## 支撑表

- `指标快照`：账号或内容在固定时间桶的历史指标。
- `评论库`：按策略采样的评论与主题标签。
- `运行日志`：每次任务的输入、输出、消费、耗时和状态。
- `失败队列`：可恢复的单条失败与人工处理状态。

字段、公式、视图和仪表盘的版本化定义位于 `templates/`。运行时只写存储字段，不写公式、Lookup 或系统字段。
